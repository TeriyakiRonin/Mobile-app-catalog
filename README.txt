ASH & CAIRN INSTALLABLE WEB APP (PWA)

WHAT IT DOES
- 125 soaps with bundled images
- Search and filter by collection
- View all four recipe versions for each soap
- Edit soap name, collection, scent profile, and all recipe text
- Edits save locally on the phone
- Export/Import edits as a JSON backup
- Works offline after the first successful load/install
- Can be added to the iPhone Home Screen as an app icon

IMPORTANT FOR IPHONE
A PWA must be served from an HTTPS website. It cannot be installed from a file:// folder.
Upload this folder to any static host (GitHub Pages, Netlify, Cloudflare Pages, Vercel, etc.).

ON IPHONE
1. Open the HTTPS site in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Tap Add.

The Ash & Cairn icon will appear on your Home Screen and open full-screen like an app.
